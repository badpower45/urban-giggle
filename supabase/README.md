# دليل إعداد وربط قاعدة بيانات سوبابيز (Supabase) ونشر النظام على Vercel
## نظام بصيرة لإدارة مكاتب المحاماة (Baseera Legal SaaS)

هذا الدليل يوضح لك بالخطوات البسيطة كيفية إنشاء قاعدة بيانات على **Supabase** وتشغيل ملفات الـ SQL الجاهزة، وربطها بنظام **بصيرة** ونشره على **Vercel**.

---

### الخطوة 1: إنشاء مشروع جديد على Supabase

1. ادخل على موقع [https://supabase.com](https://supabase.com) وسجّل دخولك (أو أنشئ حساب مجاني).
2. اضغط على **"New Project"**.
3. اختر اسم للمشروع: مثلاً `baseera-legal-db`.
4. اكتب كلمة مرور قوية لقاعدة البيانات (Database Password) واحفظها.
5. اختر المنطقة (Region): يُفضل اختيار **Frankfurt (eu-central-1)** أو أي منطقة قريبة من الشرق الأوسط لأعلى سرعة استجابة.
6. اضغط **"Create new project"** وانتظر دقيقة حتى يكتمل تجهيز قاعدة البيانات.

---

### الخطوة 2: تشغيل مخطط قاعدة البيانات (Schema) والبيانات التجريبية (Seed)

1. من القائمة الجانبية في لوحة تحكم Supabase، اضغط على **SQL Editor** (أيقونة `>_`).
2. اضغط على **"New query"**.
3. افتح ملف `supabase/schema.sql` من مشروعك وانسخ كامل محتواه، ثم الصقه في الـ SQL Editor واضغط **"Run"**.
   - سيتم إنشاء جميع الجداول (الشركات، المحامين، الموكلين، التوكيلات، القضايا، الجلسات، المواعيد، المهام، محاضر الشرطة، العقود، التدقيق، والتذاكر).
   - سيتم تفعيل نظام حماية البيانات (Row Level Security - RLS) لعزل بيانات كل مكتب محاماة بسرية تامة.
   - سيتم تفعيل الدوال والمحفزات التلقائية (Triggers).
4. افتح استعلاماً جديداً (New query) وانسخ محتوى ملف `supabase/seed.sql` والصقه واضغط **"Run"** لإدخال بيانات تجريبية واقعية لمكتب محاماة وموكلين وقضايا وجلسات ومحاضر في مصر.

---

### الخطوة 3: الحصول على مفاتيح الاتصال (API Keys)

1. من القائمة الجانبية لمشروعك في Supabase، اضغط على **Project Settings** (أيقونة الترس في الأسفل).
2. اضغط على قسم **API**.
3. انسخ القيمتين التاليتين:
   - **Project URL** (مثل: `https://xyzcompany.supabase.co`)
   - **anon / public key** (مفتاح الـ API العام)

---

### الخطوة 4: ضبط المتغيرات محلياً في المشروع (.env)

أنشئ ملف باسم `.env` في المجلد الرئيسي للمشروع، وضع فيه المفاتيح كالتالي:

```env
VITE_SUPABASE_URL=https://your-project-id.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key-here
```

النظام ذكي ومصمم بتقنية **Dual-Mode**:
- إذا أضفت مفاتيح Supabase: سيتصل بالنظام السحابي فوراً ويخزن البيانات مباشرة على PostgreSQL.
- إذا لم تضع المفاتيح أو كنت غير متصل بالإنترنت: يعمل النظام بسلاسة بنظام التخزين المحلي (Local-First Offline Database) دون أي توقف أو أخطاء!

---

### الخطوة 5: نشر النظام على Vercel مع ضبط المتغيرات

تم تجهيز ملف `vercel.json` في المشروع لضمان إعادة توجيه الروابط (SPA Rewrites) بدون ظهور خطأ 404 عند تحديث الصفحات.

1. ادخل على [https://vercel.com](https://vercel.com) واضغط **"Add New Project"**.
2. اربط مستودع الـ GitHub الخاص بالمشروع.
3. قبل الضغط على **Deploy**، افتح قسم **"Environment Variables"** وأضف:
   - `VITE_SUPABASE_URL` = (رابط مشروع Supabase الخاص بك)
   - `VITE_SUPABASE_ANON_KEY` = (مفتاح الـ Anon الخاص بك)
4. اضغط **Deploy**.
5. سيعمل موقعك فوراً مع شهادة SSL مجانية ورابط سريع ومباشر.

### هيكل جداول قاعدة البيانات (Database Architecture)

| اسم الجدول | الوصف والوظيفة |
| :--- | :--- |
| `firms` | بيانات مكاتب المحاماة، الهوية، والباقة |
| `profiles` | الملفات الشخصية للمحامين والمساعدين مربوطة بـ `auth.users` |
| `firm_roles` | الأدوار والصلاحيات المخصصة للمكتب |
| `firm_members` | ربط المستخدمين بالمكتب وتحديد صفاتهم |
| `clients` | سجل الموكلين (أفراد، شركات، جهات) والأرقام القومية |
| `power_of_attorney` | التوكيلات الرسمية الصادرة من الشهر العقاري |
| `cases` | سجل القضايا والدعاوى والمحاكم والدوائر والخصوم |
| `case_sessions` | رول الجلسات وقرارات المحكمة والتأجيلات |
| `legal_deadlines` | حاسبة المواعيد القانونية والطعون (استئناف، نقض، معارضة) |
| `tasks` | إدارة مهام المكتب وتكليفات المحامين |
| `police_reports` | محاضر الشرطة والنيابات العامة وأرقام الصادر |
| `contracts` | مسودات ونماذج العقود الذكية |
| `documents` | ملفات القضايا والماسح الضوئي الذكي (OCR) |
| `billing_payments` | الأتعاب والمصروفات القضائية وسندات القبض |
| `audit_logs` | سجل التدقيق والرقابة على عمليات المكتب |
| `support_tickets` | التذاكر والشكاوى الفنية |
